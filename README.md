# Приложение 13HHH 📱

Приложение для управления напоминаниями и событиями с удобным календарем.

## ✨ Возможности

- 📅 **Календарь** - просмотр дней с событиями
- 📝 **События** - создание и управление событиями на каждый день
- ⏰ **Напоминания** - настройка напоминаний с временем и датой
- 🔔 **Уведомления** - получайте уведомления за выбранное время до события
- 📊 **Разные виды** - календарь, список событий, список напоминаний

## 🎯 Основные функции

### Календарь
- Просмотр месяцев
- Дни с событиями отмечены
- Переключение между месяцами

### События
- Добавление событий на конкретную дату
- Указание времени события
- Описание события
- Просмотр событий по дням

### Напоминания
- Создание напоминаний
- Настройка времени уведомления (например, "За 5 минут")
- Повторяющиеся напоминания

## 🛠 Технологии

- **Язык**: Kotlin
- **Min SDK**: 21 (Android 5.0)
- **Target SDK**: 33
- **Архитектура**: MVVM
- **База данных**: SQLite
- **UI**: XML Layouts
- **Уведомления**: AlarmManager + NotificationManager
